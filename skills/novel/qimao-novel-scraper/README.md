# qimao-novel-scraper

七猫小说扫榜 → 挑标杆 → 拆解前 3 章 → 生成新书设定（多候选供用户选择）的一站式技能。

## 触发词

「扫七猫」「七猫扫榜」「看看七猫新书」「挑一本标杆书」「拆解前3章」「对标写新书」「设计新书设定」「哪些小说好写/容易火/赚钱」

## 快速上手

1. 依赖 playwright MCP 浏览器工具（curl 亦可，七猫无反爬）
2. 用户给出扫榜指令（或回答 Step 0 需求采集问题）
3. 流程：扫榜（Step 1）→ 分析（Step 2）→ 挑标杆（Step 3）→ 看简介（Step 4）→ 抓前 3 章（Step 5）→ 拆解（Step 6）→ 候选设定（Step 7，必须多选用户拍板）→ 完整设定文档（Step 8）
4. 产物落盘：`小说扫榜/<书名>/{正文,材料}/`，扫榜期产物存 `小说扫榜/扫榜/`
